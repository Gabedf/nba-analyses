# 🏀 NBA Analyses — Season 2024/25

**Tech Stack:** `Python` · `Polars` · `Streamlit` · `Pandas` · `Plotly`

[🔗 **Live App on Streamlit**](https://nba-analyses.streamlit.app/)

---

## 📘 Overview

This project was built as a **personal data analysis exercise**, combining two things I truly enjoy:
**Data Science** and **Basketball (NBA)**.

The goal wasn’t to build a production-level product, but rather to **practice concepts I use at work** and explore them in a fun, visual, and meaningful way.
Even though it’s still simple and full of room for improvements, it was a great way to experiment with analytics tools while working with data I care about.

---

## 🎯 Objective

Using data from the **NBA 2024/25 season**, the project aims to:

* Explore **team and player performance metrics**.
* Apply **data manipulation with Polars** and **interactive visualization with Streamlit**.
* Create a **dashboard** summarizing key offensive metrics.

---

## 📊 Features

* **Top 3 Teams Analysis:**
  Based on multiple metrics, such as:

  * Average Points (PTS)
  * Field Goal Percentage (FG%)
  * Average 3-Point Attempts (3PA)
  * 3-Point Percentage (3P%)

* **Performance Over Time:**
  Line charts showing trends for:

  * Points (PTS)
  * Assists (AST)
  * 3-Point Shots (3P)
  * Efficiency rates

* **Team-Based Visualization:**
  Each team has its own color palette — colors are mapped dynamically and consistently across visualizations.
